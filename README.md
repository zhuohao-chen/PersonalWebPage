# Zhuohao Chen Academic Website

First version of a single-page academic personal website built with Next.js, TypeScript, and Tailwind CSS.

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Content Updates

All website content lives in `data/siteData.ts`. Replace placeholder links, project images, and the CV path there.

Place the final CV at `public/Zhuohao_Chen_CV.pdf` so the Download CV buttons work.
